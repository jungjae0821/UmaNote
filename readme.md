# 우마노트

우마무스메 한국서버 플레이어를 위한 웹 서비스입니다. 일본서버가 한국서버보다 476일 앞서 있다는 점을 이용해, 일본서버 일정을 한국서버 예상일로 바꿔 보여주고 목표 픽업까지 모일 쥬얼(사료)을 계산합니다.

로그인 없이 누구나 모든 기능을 쓸 수 있습니다.

## 기능

| 화면 | 경로 | 내용 |
| --- | --- | --- |
| 홈 | `/` | 오늘 날짜, 진행 중·다음 픽업, 오늘 앞뒤 기간의 픽업 노선도, 사료계산기에 입력한 보유 쥬얼 요약 |
| 가챠 일정 | `/gacha` | 한 달 단위 픽업 일정. 육성 우마무스메 / 서포트 카드 필터, 달 이동, 유료 쥬얼 전용·특별 가챠 표시 |
| 뽑기 시뮬레이터 | `/simulator` | 실제 배너와 제공 비율로 단차 / 10연차, 천장 포인트(200) 교환, 배너별 뽑기 기록과 통계 |
| 사료계산기 | `/calculator` | 지금 가진 쥬얼·티켓과 받을 보상을 넣고 목표 픽업을 고르면, 그날까지 모이는 쥬얼과 뽑기 횟수를 계산 |
| 생일달력 | `/birthdays` | 1월~6월 캐릭터 생일을 달별 달력으로, 다음 생일과 D-day |
| 이벤트 일정 | `/events` | 게임 이벤트를 한 달 달력에 기간 막대로 표시하고 아래에 목록으로. 경기 / 스토리 / 육성 / 기념 미션 필터 |

### 사료계산기 상세

- 입력: 무료·유료 쥬얼, 육성·서포트 티켓, 월정액, 시즌 패스(무료 / 프리미엄), 팀 경기장 클래스, 챔피언스 미팅 리그와 결승 결과, 리그 오브 히어로즈 최종 랭크, 레전드 레이스 1착 여부, 목표 픽업
- 목표로 고를 수 있는 픽업: 오늘부터 240일 안에 시작하는 픽업
- 더하는 보상: 로그인 보너스, 기간 한정 미션, 스토리 이벤트 보상, 경기 보상, 선물 등. 각 수치의 출처는 `lib/jewelSources.ts`에 적혀 있음
- 유료 쥬얼 전용 가챠는 유료 쥬얼로만 계산
- 신데렐라 그레이 방영 기념 쥬얼 캠페인은 한일 동시 진행이라 계산에서 제외

### 이벤트 일정에 넣는 이벤트

레전드 레이스, 챔피언스 미팅, 리그 오브 히어로즈, 스토리 이벤트, 기능시험, 레이싱 카니발, 팀 스카우트, 주년 기념, G1 기념, 기념 미션. 마스터즈 챌린지는 개최 날짜 자료를 찾지 못해 넣지 않았습니다.

## 규칙

- 모든 데이터는 일본서버 기준입니다.
- 한국서버 예상일 = 일본서버 날짜 + 476일(고정). 화면에는 한국서버 예상일을 메인으로, 일본서버 날짜를 보조로 함께 표시합니다.
- 캐릭터·카드 이름은 한국서버 공식 한글명을 우선하고, 없으면 일본어 원문으로 표시합니다.
- 사료계산기 입력값과 뽑기 기록은 사용하는 브라우저의 `localStorage`에만 저장되며 기기 간 동기화는 없습니다.

## 데이터 출처

외부 API를 실시간으로 호출하고, 응답은 Next.js 데이터 캐시에 둡니다.

- [umapyoi.net](https://api.umapyoi.net/): 픽업 일정, 일러스트, 생일
- [gametora.com](https://gametora.com/ko/umamusume): 배너·제공 비율, 한국어 이름, 미션·이벤트 보상, 이벤트 일정
- [uma.guide](https://uma.guide/): 게임 데이터·보상 확인용 참고 자료
- 고정 보상표(로그인 보너스, 팀 경기장, 챔피언스 미팅 등)는 공략 사이트·공식 공지를 근거로 `lib/jewelSources.ts`에 직접 정리

## 기술 스택

## 개발

```bash
npm install
```

```bash
npm run dev
```

개발 서버는 http://localhost:5640 에서 열립니다.

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 (포트 5640) |
| `npm run build` | 프로덕션 빌드 |
| `npm start` | 빌드 결과 실행 (포트 5640) |
| `npm run typecheck` | 타입 검사 |
| `npm test` | 단위 테스트 (`tests/*.test.mts`, Node 내장 테스트 러너) |
