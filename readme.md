# 우마노트

- 개요

1. 주요 기능: 가챠 (과거가챠와 미래가챠, 유료쥬얼을 사용하는 가챠 전부 포함), 사료계산기 (이벤트와 각종 보상으로 받을 수 있는 쥬얼 계산 -> 어느 픽업까지 얼마나 많은 쥬얼이 모이는지 파악 가능하도록 서비스를 사용하기 시작한 현재 값을 넣도록), 생일달력 (1월~6월까지 생일자를 달력에 표시), 이벤트 일정 (게임 내 이벤트 일정)
2. 참고 사이트

- 가챠(과거포함), 일러, 생일: https://api.umapyoi.net/
- 각종 사료량 정리: https://gametora.com/ko/umamusume
- 게임 데이터 테이블, 미션·로그인 보너스·세부 보상 보완: https://uma.guide/

3. 필수사항

- 모든 사항은 일본서버 기준으로 진행
- 일본서버와 한국서버의 간격은 476일
- 신데렐라 그레이 방영 기념 쥬얼 증정 캠페인의 경우 한국과 일본이 동시 진행했으므로 사료 계산에서 제외
- localhost:5640에서 작업진행

4. 기술 스택

- 프레임워크: Next.js
- 인증: 없음 (누구나 로그인 없이 모든 기능 사용)
- 저장: 브라우저 저장소 (사료계산기 입력값, 뽑기 기록. 기기 간 동기화 없음)
- 배포: Vercel
- 데이터: 참고 사이트 API를 실시간 호출

5. 기능 상세

- 공통
  - 로그인 없이 모든 기능 사용. 사료계산기 입력값과 뽑기 기록은 사용하는 브라우저에 저장
  - 캐릭터·카드 이름은 한국서버 공식 한글명 우선, 없으면 일본어 원문 표기
- 날짜 표시
  - 한국서버 예상일(일본서버 날짜 + 476일, 항상 고정)을 메인으로 표시하고, 일본서버 날짜는 보조로 함께 표시
- 가챠
  - 픽업 일정표: 과거·미래 픽업을 타임라인/목록으로 표시
  - 뽑기 시뮬레이터
    - 단차 / 10연차
    - 천장 포인트 적용
    - 뽑기 기록 저장 및 통계
    - 육성 우마무스메 / 서포트 카드 가챠 구분
- 사료계산기
  - 사용자 입력: 보유 쥬얼, 보유 티켓(우마무스메/서포트 카드), 월정액 구매 여부, 목표 픽업
  - 입력 시점부터 목표 픽업까지 모이는 쥬얼을 계산
  - 무료 쥬얼과 유료 쥬얼을 구분 (유료 전용 가챠는 유료 쥬얼로만 계산)
- 생일달력
  - 1월~6월 생일자만 달력에 표시 (고정 범위)
- 이벤트 일정
  - 게임 내 이벤트 일정을 한국서버 예상일 기준으로 표시 (gametora와 uma.guide 데이터 참고)
