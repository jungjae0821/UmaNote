### AI 구조안

공통: 왼쪽 고정 사이드바 내비(홈 / 가챠 일정 / 뽑기 시뮬레이터 / 사료계산기 / 생일달력). 모바일은 상단 바 + 펼치는 메뉴. 모든 날짜는 GameTora 한국서버 일정 기준, 날짜 옆에 "n일 후 시작"·"n일 남음" 같은 상대 시간.

1. 홈
   1. 페이지 제목줄: "홈" + 오른쪽에 오늘 날짜
   2. 진행 중 픽업 (가장 크게): 육성 우마무스메 / 서포트 카드 배너를 큰 카드로. 배너 이미지, 기간, 남은 시간 배지, 픽업 대상(신규/복각), 바로가기 2개(이 배너로 뽑기 시뮬레이터 / 이 픽업을 목표로 사료계산기)
   3. 다음 픽업: 진행 중 바로 아래에 같은 형식으로 조금 작게. 시작일과 "n일 후 시작"
   4. 오늘 앞뒤 픽업 기간: 오늘 선이 있는 가로 타임라인(앞 2주 ~ 뒤 6주), 막대 하나가 픽업 하나
   5. 보유 쥬얼 요약: 데스크톱은 진행 중·다음 픽업 오른쪽 좁은 열. 무료/유료 쥬얼, 티켓, 목표 픽업까지 예상 쥬얼. 입력 전이면 사료계산기로 가는 버튼만
2. 가챠 일정
   1. 달 이동: ◀ 2026년 11월 ▶ + "오늘" 버튼
   2. 필터 칩: 육성 우마무스메 / 서포트 카드 (둘 다 켜짐이 기본), 유료 쥬얼 전용·특별 가챠는 배지로 표시
   3. 보기 탭: 달력 / 목록
   4. 달력: 한 달 달력에 픽업 기간 막대, 오늘 칸 강조. 목록: 배너 카드(이미지, 기간, 픽업 대상, 유료 전용·특별 배지)
   5. 배너를 누르면 상세(픽업 대상과 제공 비율, 시뮬레이터로 가기)
   - 편하게: 처음 열면 이번 달 + 오늘 위치, 필터와 보기 탭은 브라우저에 기억
3. 뽑기 시뮬레이터
   1. 탭: 육성 우마무스메 / 서포트 카드
   2. 배너 선택 드롭다운 (기본값: 진행 중 배너)
   3. 배너 정보: 이미지, 기간, 픽업 대상과 제공 비율
   4. 뽑기 영역 (가장 크게): 단차 / 10연차 버튼, 결과 카드 10장 격자, 결과 등급 필터(★3/★2/★1)
   5. 천장: 현재 포인트 n/200, 200이 되면 픽업 대상 중 하나와 교환
   6. 기록·통계: 이 배너의 총 횟수, 쓴 쥬얼, ★3 수, 픽업 획득 수, 뽑기 기록 목록, 초기화
   - 데스크톱은 왼쪽 뽑기 영역, 오른쪽 천장·통계 열
4. 사료계산기
   1. 보유: 무료 쥬얼, 유료 쥬얼, 육성 티켓, 서포트 티켓
   2. 받을 보상: 월정액, 시즌 패스(무료/프리미엄), 팀 경기장 클래스, 챔피언스 미팅 리그·결승 결과, 리그 오브 히어로즈 랭크, 레전드 레이스 1착 여부
   3. 목표 픽업: 오늘부터 열려 있는 미래 픽업 중 선택
   4. 계산 결과 (가장 크게): 데스크톱은 오른쪽에 고정된 결과 패널, 모바일은 화면 아래 고정 요약 + 펼치기. 목표일까지 모이는 쥬얼(무료/유료), 가능한 뽑기 횟수, 천장까지 남은 횟수, 더한 보상 내역과 뺀 항목(신데렐라 그레이 캠페인)
5. 생일달력
   1. 다음 생일 (가장 크게): 캐릭터 일러스트, 이름, 날짜, D-day. 옆에 그다음 생일자 4명을 작게
   2. 달별 달력: 1월~6월 탭, 날짜 칸에 캐릭터 얼굴과 이름, 오늘 칸 강조

## 이벤트 (확정 구조)
1. 진행 중 이벤트 카드: 종류, 이름, 기간, 남은 기간. 스토리 이벤트는 보너스 캐릭터, 보상 서포트
2. 종류 필터 칩: 스토리 이벤트 / 챔피언스 미팅 / 리그 오브 히어로즈 / 레전드 레이스
3. 달별 목록(다가오는 것부터): 종류 배지, 이름, 기간, 상대 시간, 경기 조건(바장·거리)
- 가장 중요한 것: 진행 중·다가오는 이벤트를 날짜와 함께 바로 보기

## 캐릭터 (확정 구조)
목록 /characters
1. 왼쪽 필터 패널: 구분(육성/서포트), 희귀도 칩 / 접는 묶음: 서포트 타입, 각질·거리 적성, 획득 경로, 한국 출시 여부
2. 오른쪽 위: 이름 검색, 정렬(한국 출시일 / 이름), 개수
3. 카드 격자: 일러스트, 이름, 의상명, 출시 전이면 "예정" 배지
상세 /characters/[id] (별도 페이지): 큰 일러스트, 이름·의상, 한국 출시일, 나온 픽업 목록, 생일
- 가장 중요한 것: 원하는 캐릭터·카드를 빨리 찾기

## 검색 (확정 구조)
1. 사이드바 검색 또는 Ctrl+K로 가운데 모달
2. 결과를 캐릭터 / 서포트 카드 / 픽업 / 이벤트 묶음으로
3. 방향키·엔터로 이동 (캐릭터 상세, 미래시 배너 상세, 이벤트 화면)
- 가장 중요한 것: 이름 일부만 쳐도 바로 찾아지기
