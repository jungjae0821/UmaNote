# 레퍼런스 노트 (2026-11-23)
기준: 게임(우마무스메 한국서버) 플레이어용 일정·계산 유틸 웹앱, 공개 커뮤니티 서비스, 앱 화면

## 사이트별

### 1. 몰루로그 — https://mollulog.net/
사용자가 가져오고 싶은 점: 화면 배치와 UI, 기능들

- 측정값 (1280x800, 홈)
  - 폰트: 본문 Pretendard. 경기천년제목(GyeonggiTitle) 파일은 로고 글자에만 씀
  - 크기 단계: 페이지 제목 24px/700/행간 32px, 섹션 제목 20px/600/28px, 카드 제목 18px/600/28px, 본문 16px/400/24px, 보조 14px/300/20px, 라벨·태그 12px/600/16px (가장 많이 쓰임, 133개)
  - 면 색: 페이지 oklch(0.269 0 0), 카드 oklch(0.33 0 0) — 무채색 다크. 강조는 빨강 oklch(0.704 0.191 22) / 파랑 oklch(0.707 0.165 254) / 보라 oklch(0.714 0.203 305)를 태그 배경에 씀
  - 글자 색: 본문 oklch(0.85 0 0), 제목 oklch(0.985 0 0), 보조 oklch(0.78 0 0)
  - 모서리: 8px(카드·버튼 대부분), 10px, 6px, 알약형(태그)
  - 모션: 0.12s cubic-bezier(0.2, 0, 0, 1) 거의 전부
  - 간격: 4px·12px 위주의 촘촘한 간격, 콘텐츠 최대 폭 1536px
- 관찰
  - 왼쪽 고정 사이드바 내비(검색, 홈, 분류별 접히는 메뉴 묶음: 게임 정보 / 플래너·계산기 / 커뮤니티). 상단 헤더 없음
  - 홈 = "진행 중인 컨텐츠" 대시보드. 본문 2단(넓은 왼쪽 + 오른쪽 좁은 열)
  - 맨 위에 진행 중 이벤트를 큰 배너 이미지(641x320)로, 이미지 위에 이벤트 이름과 "21시간 남음" 같은 남은 시간 배지, 관련 계산기·시뮬레이션으로 바로 가는 버튼
  - 그 아래 "학생 모집"(픽업) 카드: 캐릭터 세로 카드(112x127) 가로 나열, 카드마다 신규/복각 배지, 이름, 속성 태그. 끝에 "다음 모집 · 11/24 시작"
  - 이어서 레이드·그 외 컨텐츠(진행 중/예정, n일 후 시작), 다가오는 생일(이름, 날짜, "오늘"/"n일 후")
  - 미래시 화면: 왼쪽에 컨텐츠 필터 패널(분류별 칩 버튼, 토글 스위치), 오른쪽에 타임라인 / 목록 / 일정표 탭. 타임라인은 세로 선에 항목을 매달고, 항목마다 기간·"내일 종료" 같은 상대 시간 + 픽업 캐릭터 카드
- 가져올 것: 사이드바 내비, 홈 맨 위 진행 중 픽업 큰 배너 + 남은 시간 배지 + 관련 기능 바로가기, 다음 픽업 시작일 표시, 상대 시간 표기("n일 후"), 필터 칩 + 보기 방식 탭, 생일 "n일 후" 목록, 촘촘한 12px 라벨 체계
- 버릴 것: Pretendard(고정 규칙상 경기천년체 사용), 커뮤니티 피드·유튜브 열(우마노트에 없는 기능), 보조 글자 대비는 다시 확인 필요

### 2. GameTora 가챠 시뮬레이터 — https://gametora.com/ko/umamusume/gacha-simulator
사용자가 가져오고 싶은 점: 가챠 시뮬레이터 기능을 비슷하게

- 측정값: 측정 생략 (사용자가 기능만 참고하라고 함. 시각 값은 가져오지 않음)
- 관찰 (기능 구성)
  - 위쪽 탭: 캐릭터 가차 / 서포트 카드 가차
  - "진행 중인 픽업" 드롭다운으로 과거·미래 배너 전체 중 하나 선택 (#번호 + 기간)
  - 선택한 배너: 배너 이미지, 기간, 픽업 대상 목록과 각 제공 비율("신규, 0.75%"), 영상 미리보기 링크
  - 시뮬레이터: 1번 가차 / 10번 가차 버튼, 결과 카드 10장 격자(3-2-3-2 배치, 뒤집기 연출), 결과 필터(★3/★2/★1)
  - 누적 통계: 총 횟수, 쥬얼 소모, 3★ 획득 수, 초기화
  - 참고: 한국어 페이지는 한국(카카오) 서버 기준 일정을 보여줌 (2026-11-19 ~ 12-03 진행 중, 2027년 미래 일정도 있음)
- 가져올 것: 캐릭터/서포트 탭, 배너 선택 + 배너 정보(픽업 대상과 비율), 1회/10회, 결과 카드 격자, 결과 등급 필터, 총 횟수·쥬얼 소모·3★ 수 통계, 초기화
- 버릴 것: 광고 영역, 시각 스타일 전체

- 두 사이트 모두 배너(픽업)를 기간과 함께 이미지 카드로 보여주고, 픽업 대상 캐릭터를 개별 카드/목록으로 나열
